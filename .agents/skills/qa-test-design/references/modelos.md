# Modelos de saída

Adaptar os campos ao formato do projeto. Não preencher resultados observados com exemplos.

## Caso de teste

### CT-XXX — Comportamento verificável

- **História / critério / fonte:**
- **Objetivo:**
- **Tipo:** positivo, negativo, fronteira, permissão ou estado.
- **Prioridade e risco:**
- **Pré-condições:** perfil, estado e preparação necessários.
- **Dados:** valores concretos; demais campos válidos quando se testa uma fronteira.
- **Passos:** ações numeradas, suficientes para reprodução.
- **Resultado esperado:** efeito observável e persistência quando relevante.
- **Resultado obtido / evidência:** preencher somente após executar.
- **Status inicial:** Não executado.

Quando houver variações, usar uma tabela com entrada, resultado esperado e resultado obtido por execução.
