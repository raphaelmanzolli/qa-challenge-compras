# BUG-004 — PDF exibe menor lance unitário divergente da API e do resultado

- **Estado:** aberto; reproduzido em 26/10/2026.
- **Fonte:** HU04 CA09.
- **Ambiente:** Linux, imagem `qa-challenge-compras:1.0`, Chromium, perfil fornecedor.
- **Severidade:** alta; relatório financeiro contém valores conflitantes.
- **Prioridade:** P1.

## Reprodução

1. Como comprador, criar compra com quantidade 3 e teto unitário R$ 120,50; publicar.
2. Aguardar ABERTA; Beta envia R$ 120,50 e Alpha envia R$ 119,50.
3. Aguardar ENCERRADA e homologar como comprador.
4. Como fornecedor, abrir Resultado e acionar “Baixar relatório (PDF)”.
5. Comparar “Menor lance unitario” do PDF com `menorLanceUnitario` de `GET /api/compras/{id}` e com o vencedor da tela.

**Esperado:** R$ 119,50 nos três pontos; quantidade 3 e total vencedor R$ 358,50.

**Obtido:** “Menor lance unitario: R$ 120,00” no PDF; API e tela mostram R$ 119,50. O próprio PDF informa corretamente “Valor unitario vencedor: R$ 119,50”.

| Compra                       | Menor lance na API | Menor lance no PDF | Resultado |
| ---------------------------- | ------------------ | ------------------ | --------- |
| CD-000467 — centavos         | R$ 119,50          | R$ 120,00          | Reprovado |
| CD-000466 — controle inteiro | R$ 449,00          | R$ 449,00          | Aprovado  |

**Evidências:** [PDF com centavos](../../resultados/bugs/pdf-2026-10-26/centavos.pdf), [API](../../resultados/bugs/pdf-2026-10-26/centavos-api.json), [tela](../../resultados/bugs/pdf-2026-10-26/centavos.png) e [comparação](../../resultados/bugs/pdf-2026-10-26/centavos-comparacao.json). Controle: [PDF inteiro](../../resultados/bugs/pdf-2026-10-26/inteiros.pdf) e [comparação](../../resultados/bugs/pdf-2026-10-26/inteiros-comparacao.json).

**Impacto:** o documento apresenta informação financeira inconsistente com a API, a tela e outro campo do próprio PDF. Não foi demonstrado vencedor incorreto ou corrupção dos lances. A causa interna não foi investigada.

**Reteste:** repetir as duas massas e conferir máximo unitário, menor lance, valor unitário vencedor e total vencedor. A conferência do PDF é manual; não faz parte dos 28 testes automatizados.
