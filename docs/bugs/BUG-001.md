# BUG-001 — Detalhe da compra exibe total estimado incorreto para valores com centavos

- **Estado:** aberto; reproduzido em 26/10/2026.
- **História / critério / caso:** HU01 / CA05 / CT-006.
- **Severidade:** média; informação monetária incorreta na interface, com valores corretos na API nas massas testadas.
- **Prioridade:** P1; o total estimado é uma informação central para a conferência da compra.
- **Ambiente:** Linux, imagem `qa-challenge-compras:1.0`, Playwright Chromium, perfil comprador.

## Reprodução

1. Como comprador, acessar Nova compra.
2. Preencher objeto válido, quantidade `3` e valor máximo unitário `120.50`.
3. Salvar o rascunho e conferir o valor total estimado no detalhe.
4. Comparar com `GET /api/compras/{id}`.

**Esperado:** R$ 361,50, pois 3 × R$ 120,50 = R$ 361,50.

**Obtido:** o detalhe mostra R$ 363,00; a API retorna R$ 361,50.

| Massa      | Compra / evidência                                                          | Esperado | Detalhe obtido | API obtida |
| ---------- | --------------------------------------------------------------------------- | -------- | -------------- | ---------- |
| 1 × 0,01   | [CD-000468](../../resultados/automacao-2026-10-26/25-comparacao-total.json) | 0,01     | R$ 0,00        | 0,01       |
| 3 × 0,10   | [CD-000469](../../resultados/automacao-2026-10-26/26-comparacao-total.json) | 0,30     | R$ 0,00        | 0,30       |
| 3 × 120,50 | [CD-000470](../../resultados/automacao-2026-10-26/27-comparacao-total.json) | 361,50   | R$ 363,00      | 361,50     |
| 4 × 450,00 | [CD-000471](../../resultados/automacao-2026-10-26/28-comparacao-total.json) | 1.800,00 | R$ 1.800,00    | 1.800,00   |

**Frequência:** as três massas com centavos falharam; o controle inteiro passou. Cada compra foi criada separadamente. As respostas e os valores exibidos estão nos anexos da tabela.

**Impacto:** o comprador confere uma estimativa incorreta, que pode ser maior que o valor real ou aparecer zerada. Não foi demonstrada alteração indevida dos valores persistidos nem do vencedor. A causa interna não foi investigada.

**Reteste:** `npx playwright test tests/e2e/total-estimado.spec.mjs`.
